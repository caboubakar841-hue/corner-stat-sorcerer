# Corner Stat Sorcerer

Un site pour analyser les matchs de football (estimation des buts, vainqueur probable et nombre de corners) à partir des données réelles d'équipes et de matchs.

Intégrer l'historique des confrontations directes sous les blocs de buts et de corners, avec les résultats récents et leur influence sur les estimations.

N'afficher que les matchs ou prédictions où la probabilité atteint au moins 70% de chance.
